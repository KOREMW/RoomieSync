## 보여줄 핵심 기능 (우선순위)

1. **두 페인 통합** — 가사 분담 + 공동 지출 정산을 한 앱에서
2. **채무 단순화** — 송금 횟수 최소화 (가장 강한 차별점, 비교 컷)
3. **날짜 기준 가사 회전** — 완료해도 그날 담당자 유지, 날짜가 지나야 회전
4. **멤버 간 동기화 + 알림 + 알림함** — Firestore + 로컬 알림
5. **통계/게이미피케이션** — 공정 지수 · 레벨 · 뱃지

## 촬영 팁

- **채워진 화면**: 시뮬레이터를 `-DemoSeed`로 실행하면 시드된 그룹(3인·가사 4·지출 5)으로 바로 진입해 온보딩 없이 모든 탭이 채워진 상태로 보인다. 탭 고정이 필요하면 `-DemoTab expense` 처럼 지정.
- **두 기기 동기화/알림 장면**: 실제 폰 + 시뮬레이터(또는 시뮬레이터 2대)로 같은 그룹에 들어가 한쪽 동작 → 다른쪽 새로고침 시 알림이 뜨는 순간을 녹화.
- **녹화**: `⇧⌘5`(마이크 켜고 나레이션 동시 녹음) 또는 시뮬레이터 File → Record Screen(`⌘R`, 영상만). 시뮬레이터 창 영역만 선택 녹화하면 깔끔하다.
- **편집/자막**: iMovie 무료로 충분. 자막은 화면 하단, 한 컷 1.5~8초.
- **길이 점검**: 나레이션을 먼저 녹음해 길이를 재고, 화면을 거기에 맞춰 자른다.
